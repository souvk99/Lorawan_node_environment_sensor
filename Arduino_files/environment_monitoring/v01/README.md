# V01

Arduino project kept in a GitHub-friendly structure with an Arduino IDE-compatible copy.

## Purpose
- This project contains the deployed Arduino sketch as it was used in the workspace.
- The Arduino-compatible working copy is kept under `arduinoCode/`.

## Sketch entry point
- Open the `.ino` file located in `arduinoCode/` with the Arduino IDE.

## Notes
- This folder is suitable for independent GitHub upload.
- Keep the original project files in place for traceability and deployment history.
